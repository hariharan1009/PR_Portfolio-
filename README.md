## 🚀 Live Demo & Deployment

You can deploy this repository directly using **GitHub Pages**:
1. Go to your repository settings on GitHub (**Settings** > **Pages**).
2. Under **Build and deployment** > **Branch**, select `main` (or `master`) branch and folder `/ (root)`.
3. Click **Save**. Your portfolio will be live at `https://<your-username>.github.io/<repository-name>/`!

## ✨ Features

- 🌌 **Futuristic Dark Aesthetic**: Cybernetic background grid, glassmorphism cards, and neon cyan / electric violet glowing accents.
- 💻 **Interactive Code Terminal**: Embedded Java/ECE code snippet with syntax highlighting in the hero section.
- 📊 **Key Metrics & Statistics**: Displays academic achievements (9.02/10 CGPA), projects, and leadership roles.
- 🛠️ **Skills Matrix**: Categorized proficiency cards with animated progress indicators for Programming, Embedded Systems, and Tools.
- 📅 **Experience Timeline**: Vertical glowing timeline for industrial internships at Power Integrated Solutions.
- 🚀 **Featured Projects Showcase**:
  - **Airline Reservation System** (Java Desktop App)
  - **Expense Tracker** (HTML • CSS • MySQL • XAMPP)
  - **AutoSense Smart Home System** (Arduino • IoT • Sensors)
- 🏆 **Achievements Timeline**: Highlights paper presentation honors (ISTE, IETE, GCE Trichy) and IEEE event coordination.
- 📄 **Interactive Resume Viewer**: Formatted printable resume modal with PDF export support.
- 📬 **Interactive Contact Form & One-Click Email Copy**: Client-side validation and toast notifications.
